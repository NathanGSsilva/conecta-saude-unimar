## Descrição do Problema
Atualmente, muitos familiares que tem seus entes internados em hospitais não conseguem acompanhá-los como gostariam devido ao trabalho e outras obrigações. Não conseguem acompanhar os medicamentos aplicados, nutrição, evolução dos pacientes e até receber notícias ao longo do dia.

## Objetivo
Desenvolver um sistema web que permita o familiar do paciente acompanhar as notícias médicas em 
#Fluxo Figma
login -> pagina inicial (nova internação; pacientes ativos) -> nova internação (informações + escolha de leitos + novo ID do paciente)
pacientes ativos (mostra leitos ocupados e os IDs) -> ID (área para upload de documentação diária + observações + receber alta + transferência de leito)
